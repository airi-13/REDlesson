## フォーム送信・メール設定

- 各フォームは共通関数 `RED.submitApplication()` を使い、GASの受付結果を受付IDで照会します。画面はGAS側の処理結果が確認できてから完了表示へ進みます。
- GASの `Code.gs` を変更した場合は、Apps Script側にも反映し、ウェブアプリを新しいバージョンで再デプロイしてください。GitHub上のGASファイル変更だけでは、公開中のGASには反映されません。
- 管理側の受信先・返信先は `tennodai.red+form@gmail.com` に統一しています。Gmailのプラスアドレスは受信先として使えますが、送信元として表示するには、Gmailの「他のメールアドレスを追加（メールの送信元）」でエイリアス設定が必要です。設定済みの場合、GASはその送信元を利用します。未設定の場合は実行アカウントのアドレスから送信し、返信先をフォーム用アドレスにします。
